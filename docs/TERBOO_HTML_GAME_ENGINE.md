# TERBOO ARCADE — محرك عرض الألعاب HTML 3D

الملفات الأساسية: `src/lib/terboo-html-game.js` · `src/lib/terboo-game-design-system.js` · `src/lib/terboo-arcade/render.js` · `src/lib/terboo-arcade/whatsapp.js` · `src/lib/terboo-visual-response.js`.

## المكونات

| المكوّن | الدور |
|---|---|
| `buildGameHtml(view)` | تحويل حالة العرض إلى مستند HTML مستقل مع CSS مدمج واتجاه RTL/LTR. |
| `buildTextGameHtml(...)` | بطاقة HTML ثلاثية الأبعاد للرسائل والحالات النصية في الألعاب القديمة. |
| `buildArcadeCatalogHtml(items)` | كتالوج HTML للألعاب مع بطاقات responsive. |
| `htmlGameRegistry` | قوالب محلية للوحة الشبكة والمسار والسجلات النصية. لوحة `view.image` مثل وردل تُحوّل كذلك إلى HTML؛ لا تُرفق كصورة. |
| `validateTemplate(html)` | رفض السكربتات/الإطارات/النماذج والسمات التنفيذية والبروتوكولات الخطرة والموارد الخارجية والحجم فوق 64KB. |
| `encodeTransport` / `relayTransport` | بناء حمولة rich HTML والتحقق من ترميز WAProto وفكها وإعادة التحقق منها. |
| `ACTION_BRIDGE` | يظل معطلاً؛ لم نثبت قناة نقرة HTML تصل إلى الخادم. لا يُدّعى أن عناصر HTML تنفّذ الحركات. |
| `buttonsView` | أزرار وقوائم واتساب الأصلية، تحمل Action ID وnonce النسخة؛ الخادم يعيد التحقق من الحركة. |
| `/play/<token>` | اللعب التفاعلي الكامل عبر الموقع باستخدام API الخادم، وليس عبر JS داخل بطاقة واتساب. |

## سياسة العرض

كل غرفة من المحرك الموحّد ترسل محاولة بطاقة HTML 3D، مع إبقاء النص والأزرار الأصلية متاحة. قيمة `uiMode` داخل تعريف اللعبة ما زالت تحدد طبيعة قواعد الإدخال واللوحة، لكنها لم تعد تختار بين صورة أو HTML. مولّد SVG/PNG/JPEG الخاص بألواح الأركيد أزيل من مسار العرض. كذلك أضيف HTML للكتالوج والتصنيفات وتفاصيل الألعاب، ولرسائل الألعاب القديمة المحددة التي كانت تعرض معاينات صور.

| نوع اللوحة | شكل HTML |
|---|---|
| `grid` | شبكة خلايا ثلاثية الأبعاد مع إبراز الخلايا، الألوان، القطع، وحالات الفوز. |
| `track` | مسار شبكي مع رموز اللاعبين والسلالم والثعابين. |
| `lines` | سجلات وحالات نصية آمنة داخل لوحة زجاجية. |
| `view.image` | إذا كان تعريف اللعبة يقدّم لوحة بصرية إضافية (مثل وردل)، تُعرض تلك اللوحة HTML بدلاً من PNG. |

## التصميم

ثيمات NEON وMIDNIGHT وCYBER وCLASSIC وMINIMAL وFANTASY. التصميم يضم طبقات bevel/glass، ظلالاً وحواف مرتفعة، glow، لوحات responsive، ودعم RTL/LTR و`prefers-reduced-motion`. صفحة اللعب بالموقع حصلت على تحسينات 3D كذلك.

## الأمان وحدود العميل

لا يُضمَّن JavaScript داخل بطاقة HTML، ولا توجد هوية Meta أو شهادات أو تواقيع مصطنعة. الحمولة لا تحسم نتائج اللعبة. التفاعل الموثوق عبر أزرار واتساب/المدخل النصي، أو من خلال صفحة اللعب على الموقع. عرض `richResponseMessage/unifiedResponse` ما زال يعتمد على عميل واتساب ولم يمكن إثباته في بيئة الفحص الحالية. لتعطيل محاولة النقل التجريبية عيّن `TERBOO_ARCADE_HTML=off`؛ الافتراضي بعد الترحيل هو `rich`.
