# ✈️ Terboo VPS على تيليجرام

بوت تيليجرام **منفصل** يدير VPS للعميل والمالك، ويشغّل نفس نظام الإدارة الموجود في واتساب.

## مكوّنات مشتركة مع بوت واتساب

البوتان يستخدمان نفس:

- خدمة Virtualizor.
- سجل الإسناد (`data/vps/entitlements.json`).
- الصلاحيات وحدود المعدّل.
- الباقات والنصوص بثلاث لغات.

نتيجة المشاركة:

- لا يُسند VPS واحد لشخصين على المنصتين.
- مالك واتساب يرى مشتري تيليجرام في قائمته.

## التشغيل

1. **إنشاء البوت:** من [@BotFather](https://t.me/BotFather) أنشئ بوتاً جديداً وانسخ التوكن.
2. **الإعداد:** في `config.js` ضع القيم التالية:
   ```js
   telegram: {
     vps: {
       enabled: true,
       token: "…",              // أو متغير البيئة TERBOO_TG_VPS_TOKEN
       ownerIds: [123456789],   // معرّفك الرقمي — أرسل /id للبوت لتعرفه
       ownerUsername: "",       // اسم مستخدمك (بدون @) لزر «تواصل مع المالك»
       language: "ar",
     },
   },
   ```
   - التوكن سر: يُسجَّل للإخفاء عند الإقلاع، ولا يظهر في أي رسالة أو سجل.
   - متغيرات البيئة تتغلب على `config.js`: `TERBOO_TG_VPS_TOKEN` و`TERBOO_TG_VPS_OWNERS` (معرّفات مفصولة بفواصل).
3. **التشغيل:** شغّل البوت في عملية مستقلة بجانب بوت واتساب:
   ```bash
   npm run telegram
   # أو مع pm2:
   pm2 start "npm run telegram" --name terboo-telegram
   ```
4. **معرفة معرّفك:** أول مرة أرسل `/id` للبوت، ثم ضع المعرّف في `ownerIds` وأعد التشغيل.

## العميل

| الأمر / الزر | الوظيفة |
|---|---|
| `/start` | ترحيب بصورة الهوية، ومعرّفك، وأزرار: سيرفراتي · الباقات · اللغة |
| `/myvps` | لوحة السيرفر: الحالة · IP · النظام · الموارد · الباقة · الانتهاء |
| ⚡ الطاقة | تشغيل · إعادة تشغيل · إيقاف · فصل الطاقة (الخطِر بزر تأكيد لمرة واحدة) |
| 🛠️ النظام | تغيير اسم المضيف · إعادة تثبيت النظام (اختيار النظام ← تأكيد ← كلمة مرور) |
| 🔐 الأمان | تغيير كلمة المرور · VNC |
| 🧰 الأدوات | الخدمات وإعادة تشغيل خدمة |
| 🗄️ النسخ | النسخ الاحتياطية والاستعادة |
| `/plans` | صور الباقات من الهوية + المواصفات والأسعار + زر التواصل |
| `/lang` | العربية · English · Español |

**ملاحظات:**

- تظهر للعميل الإجراءات المتاحة فعلاً لسيرفره فقط، أي الإجراءات التي فعّلها له المالك.
- بعد إعادة التثبيت أو الاستعادة يتابع البوت حالة السيرفر، ويبلّغ العميل مرتين: عند بدء التجهيز، وعند عودة السيرفر للعمل.

## المالك

| الأمر / الزر | الوظيفة |
|---|---|
| `/admin` | مركز الإدارة: حالة الطبقات · عدد المشترين بكل حالة · ينتهي خلال 7 أيام |
| 🧭 إسناد جديد | معالج من 4 خطوات: سيرفر متاح ← **معرّف تيليجرام** ← الباقة ← المدة ← تأكيد |
| `/assign <ID> <VPS> [باقة] [أيام]` | إسناد سريع، مثل `/assign 123456789 12902 std-1 30` |
| 🖥️ السيرفرات | كل سيرفرات الحساب (مع المسند له) · المتاح للإسناد · بطاقة كل VPS |
| 📋 المشترون | الكل · حسب الحالة · ينتهي قريباً |
| `/find <ID>` | بحث بمعرّف تيليجرام أو رقم واتساب |
| بطاقة الإسناد | تعليق/استعادة · تاريخ الانتهاء · الميزات (تفعيل/تعطيل كل إجراء) · الحدود · سحب · فك الإسناد · إعادة الإشعار |
| 🔌 لوحة الإدارة | حالة VPS بالـID · تشغيل/إيقاف · تعليق عند المزوّد · مستخدمو اللوحة (إن فُعّلت `virtualizor.admin`) |

**ماذا يحدث عند الإسناد:**

1. البوت يتحقق أن الـVPS موجود في الحساب.
2. يرفض إن كان الـVPS مسنداً لغيره، على أي منصة.
3. يبلّغ المشتري برسالة فيها زر لوحة التحكم.

**إن لم يكن المستخدم قد بدأ البوت:** تيليجرام لا يسمح للبوت ببدء محادثة، فيتم الإسناد ويُبلَّغ المالك بذلك صراحةً. بعدها يرسل المستخدم `/start`، ويعيد المالك الإشعار من بطاقة الإسناد.

## الأمان

- **الدردشات الخاصة فقط:** في المجموعات يرد البوت برابط للخاص، ولا يعرض أي بيانات.
- **الأزرار مربوطة بصاحبها:** لا يضغطها غيره، وتنتهي بعد 30 دقيقة. أزرار التأكيد لمرة واحدة.
- **كلمات المرور:** تُحذف من الدردشة فور قراءتها، ولا تُخزَّن، ولا تظهر في أي رد.
- **بيانات VNC:** تُحذف رسالتها تلقائياً بعد دقيقتين.
- **صلاحيات المالك:** بمعرّفات `ownerIds` فقط، وأوامره ترفض أي شخص آخر.
- **الهوية:** المعرّف الرقمي لتيليجرام (`tg:<id>`)، لا اسم المستخدم القابل للتغيير، ولا مطابقة جزئية للمعرّفات.

## الاختبار

```bash
node tests/terboo-telegram-vps.test.mjs
```

الاختبار يستخدم خادماً وهمياً لـTelegram Bot API وآخر لـVirtualizor، ويغطي 12 سيناريو:

1. الأدوار.
2. المجموعات.
3. معالج الإسناد.
4. منع الإسناد المزدوج بين المنصتين.
5. ملكية الأزرار.
6. الطاقة بتأكيد.
7. اسم المضيف، وكلمة المرور السرية.
8. إعادة التثبيت مع المتابعة.
9. VNC.
10. الإسناد السريع، ومستخدم لم يبدأ البوت.
11. التعليق يقطع الوصول.
12. عدم تسرّب التوكن، والـlong polling.
