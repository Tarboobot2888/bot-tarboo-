## 1) الهوية (§4–§7، §61)

- كل الهوية المحلية أصبحت **Terboo / تيربو / بوت تيربو** (نص، أصول، شخصيات، رسائل).
- **163 ملفاً** `tarboo-*` → `terboo-*` مع إصلاح كل الاستيرادات؛ الخريطة في `tools/terboo-rename-map.json`.
- الأوامر القديمة (`تاربو`، `تغيير_صورة_tarboo2/3`) بقيت **مرادفات توافق** مخفية من العرض.
- **Brand Lock** (`src/lib/terboo-brand.js`): الذكاء لا يترجم الاسم ولا يغيّره (لا «طربوش» ولا «تاربو»)،

- لم تُمس القيم الخارجية: مفاتيح API، الحزمة الخارجية `maro` (npm:ourin-baileys)، ومعرّفات روابط المطوّر.

## 2) نواة الذكاء الموحّدة (§8–§18، §38–§41، §52–§53)

**مسار واحد لكل الذكاء:** Message → Scope → Context → Memory → Intent → Tool/Command/Chat/Agent → Permission → Execution → Response → Memory Update.
Auto AI وكل واجهات الدردشة ترد عبر `composeReply` في النواة؛ لا ملف خارج النواة يستدعي المزوّدين (يثبته اختبار).

**السرعة:**
- مزوّد واحد لكل رسالة، والبديل **فقط** عند مهلة/خطأ HTTP/نتيجة فارغة/مزوّد غير متاح.
- مهلات لكل نوع مهمة + ميزانية إجمالية، قاطع دائرة (3 إخفاقات ⇒ تبريد 60ث)، ترتيب البدائل بزمن EWMA.
- الذاكرة تُحدَّث في الخلفية بعد الرد، ولا تأخير «كتابة» مصطنع.
- مقاييس p50/p95 لكل مرحلة وTTFT في `terboo-latency.js` (تظهر في تشخيص المالك).
- **منع المعالجة المزدوجة:** نفس معرّف الرسالة ونصها في نفس المسار لا يُعالج مرتين (10 دقائق) — فوق إسقاط الاتصال الفوري.
- **حد الطلبات بلا صمت:** كان الحد يُسقط الرسالة الثانية خلال 4 ثوانٍ بصمت؛ الآن تنتظر وتُجاب، وما زاد عن الطابور يأخذ ⏳.

**جودة المحادثة — Response Diversity Engine** (`terboo-ai-diversity.js`):
- لا إعادة تعريف «أنا تيربو…» لمن يعرف البوت (إلا إذا سأل «مين انت؟»).
- لا تكرار لنفس البداية/الخاتمة العامة/تسلسل الإيموجي؛ التحية المكرّرة تُستبدل بتحية مختلفة بلغة المستخدم
  حسب حالة المحادثة (أول مرة/رجوع) — بلا عشوائية، ومعزولة لكل محادثة.
- فهم المتابعات (رجوع/تعديل/تكرار/هدف جديد)، ملخّص دلالي، وذاكرة معزولة لكل خاص/عضو-في-مجموعة/مجموعة.
- تحكّم المستخدم في ذاكرته بثلاث لغات: عرض · حذف · حذف آخر معلومة · حذف الكل · تعطيل · تفعيل.

**الأخطاء — Error Guard** (`terboo-error-guard.js`): كل خطأ يُسجَّل ويُصنَّف (مهلة، شبكة، حد طلبات، غير موجود،
مرفوض، خادم، حجم، داخلي…) ويُعرض بلغة المستخدم. عند حدّ الإرسال لغير المالك تُحذف Stack Traces والمسارات،
وتُستبدل عبارات axios/Node/JS التقنية برسالة مصنّفة مترجمة. المالك في الخاص يرى التفاصيل للتشخيص.

## 3) سجل أدوات السكرابرات (§19–§27، §49–§50، §57)

- `src/lib/terboo-scraper-registry.js`: **63/63** ملفاً من `src/scraper` مسجّلة بصادراتها الحقيقية ومخطط إدخال/إخراج ومهلة وبدائل.
- المسار: تحقق من الإدخال → الصلاحية → التنفيذ (البلوقن الأصلي أولاً) → تحقق من النتيجة → إرسال ذكي للوسائط.
- اختيار تلقائي للأداة من الرابط أو الطلب بثلاث لغات، وfailover بحد أقصى نداءين، وقاطع دائرة لكل سكرابر.
- المالك يفحص/يختبر/يقارن السكرابرات بكلام طبيعي. اختبار E2E يغطي YouTube · TikTok · Spotify · MediaFire ·
  Reddit · X · Instagram · أدوات الصور · البحث · مزوّدي الذكاء.

## 4) القوائم (§28–§32، §58–§59)

**السبب الجذري:** القائمة الرئيسية والأقسام كانت تُرسل لهدف LID غير محلول، والرئيسية بنمط `buttonsMessage` قديم
والأقسام بـ`externalAdReply` داخل `interactiveMessage`، والأخطاء تُبتلع بصمت — بينما الإعدادات والمزيد بالشكل الصحيح.

**الإصلاح — Menu Delivery Layer** (`terboo-menu-delivery.js`): هدف محلول دائماً (LID → رقم، ولا إرسال للبوت نفسه)،
اقتباس الرسالة الحقيقية، طبقات Native Flow بصورة → Native Flow → أزرار → نص، سجل تسليم لكل طبقة
(الهدف، النوع، معرّف الرسالة، المسار، سبب الانتقال)، ورفض الخادم اللاحق (ack ERROR) يُسقط للطبقة التالية تلقائياً.
كل رسائل واتساب التفاعلية في البوت تمر بمهايئ المقبس نفسه.

**الأزرار العائمة:** شكل القائمة الرئيسية الأول (الافتراضي) يعود كما كان — أزرار كلاسيكية عائمة تحت الرسالة
مع بطاقة البوت وزر «📂 الأقسام» للقائمة المنسدلة — لكن عبر طبقة التسليم نفسها (هدف محلول، اقتباس، سجل)،
وإن رفضها جهاز المستلم تُرسل تلقائياً بصيغة Native Flow بصورة البوت ثم نص.

## 5) التصميم (§33–§36، §47)

- المحرّك (`terboo-ui-theme.js`) محفوظ كأساس، **بلا backticks**؛ الصفوف بعلامة `>`:
  `> ◈ الاسم: تيربو` · `> ◈ الحالة: متصل`. كتل الكود متعددة الأسطر وحدها تبقى ```…```.
- **طبقة التصميم الموحّدة** (`terboo-design.js`) عند حدّ الإرسال: أي بلوقن قديم يظهر بنفس النظام
  (إطارات `╭┈┈⬡「」` ⇒ أقسام `❋`، `┃ ◦` ⇒ صفوف `> ◈`، فواصل المحرّك)، ورموز المحرّك تتحول لرموز لغة المستلم.
  لوحات الألعاب (إكس-أو…) محتوى وظيفي لا يُمس.
- ترحيل المصدر بمحلّل AST (`tools/terboo-design-migrate.mjs`): **~4,290 تعديلاً في ~635 ملفاً**، مع إعادة
  مفاتيح الترجمة تلقائياً. `terboo-formatter.js` و`terboo-text-style.js` صارا مهايئين فوق المحرّك.
- Strict Design Audit: backticks الزخرفة · الزخارف القديمة · الخطوط المزخرفة = **0**.

  الألعاب/RPG التي يكتبها المستخدم كوسائط فتبقى كما هي حتى لا ينكسر الإدخال.
