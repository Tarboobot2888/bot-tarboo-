## ② النواة — Terboo Intelligence Kernel

`src/lib/terboo-ai-core.js` هي الآن **طبقة Orchestrator واحدة**:

```
Message → Context → Memory → Intent → Command/Chat/Agent
        → Permission → Tool/Plugin → Result → Memory Update → Response
```

الأنظمة القديمة لم تُحذف؛ صارت مزوّدات خلف `src/lib/terboo-ai-providers.js`:
Gemini · GPT · DeepSeek · NVIDIA. و`terboo-ai-assistant.js` بقي بكل أسمائه
المصدَّرة كواجهة (Facade) فوق النواة، فلم يتغيّر أي نداء قائم في `handler.js`
أو في البلوقنات أو في الاختبارات.

### أنواع القرار (7)

`CHAT` · `COMMAND` · `AGENT` · `PROJECT_OPERATION` · `MEMORY_OPERATION`
· `CLARIFICATION` · `REFUSAL`

## ③ محرّك الذاكرة — أربعة نطاقات معزولة

`src/lib/terboo-ai-memory.js`

| النطاق | المفتاح | ما يحويه |
|---|---|---|
| `private:user` | `private:<user>` | محادثة الشخص في الخاص |
| `group:user` | `group:<gid>:<user>` | محادثة الشخص داخل مجموعة بعينها |
| `group` | `group:<gid>` | معرفة مشتركة عن المجموعة نفسها |
| `global` | `global` | معرفة عامة لا تخص أحداً |

**العزل مفروض بالبنية لا بالنية:** التخزين مُشجَّر (`private` ملف مستقل،
وسجل العضو لا يُوصَل إليه إلا عبر مجموعته)، ولا توجد دالة واحدة تُعيد سجلات
أكثر من شخص، وبناء مفتاح نطاق ناقص المعرّفات **يرمي خطأ** بدل أن يخمّن.

لكل سجل: ذاكرة قصيرة (14 دوراً) · ملخّص متدحرج · حقائق طويلة المدى مصنّفة
· أحداث مهمّة · تفضيلات متعلّمة · آخر أمر · آخر هدف.

التصنيف: `fact` `preference` `identity` `decision` `task` `project`
`relationship` `important_context` — مع ثقة وطابع زمني و TTL اختياري.

**لا تُحفظ الأسرار إطلاقاً:** أي نص يطابق نمط مفتاح/توكن/كلمة مرور يُرفض
تخزينه كحقيقة، ويُنقَّح داخل نص المحادثة قبل الحفظ وقبل الإرسال لأي نموذج.

حلّ الإشارة (§6): الضمائر («هو»، «وهو»، «ده»)، المتابعة («خليها زرقاء»،

بالعربية والإنجليزية والإسبانية.

> ملاحظة تقنية: `\b` في JavaScript مبنية على `\w` اللاتينية ولا تصلح حدّاً
> للعربية. استُبدلت بنظرة خلفية/أمامية على أي حرف، مع السماح بحرف عطف واحد

**AutoAI أيضاً**: التاريخ المُرسَل للنموذج صار يأتي من النطاق المعزول لهذه
المحادثة، والجلسة القديمة احتياط فقط. فلا يصل النموذج تاريخُ محادثة أخرى.

## ⑥ الصلاحيات — بلا أي تكرار

النواة لا تملك نظام صلاحيات خاصاً بها. عند اختيار أمر تُعاد كتابة الرسالة
كأمر حقيقي، ثم يكمل `handler.js` مساره الطبيعي بكل فحوصاته:

· Owner-only · Group-only · Private-only.

البوت ليس مشرفاً، أو أمر يحتاج هدفاً بلا هدف واضح.

الممنوع **مفروض بالكود**:

| الممنوع | كيف مُنع |
