## 3. زر تغيير اللغة

يظهر في:

- **القائمة الرئيسية** — قسم «الإعدادات» داخل القائمة المنسدلة + زر Quick Reply في الشكل 2.
- **قائمة كل الأوامر** (`allmenu`) — نفس القسم.
- **واجهة الحساب** (`بروفايل`) — زر أفقي بجوار زر القائمة.
- **الأمر المباشر** `لغة` / `language` / `lang` / `idioma`.

آلية العمل:

```
ضغط الزر → terboo_language_ar|en|es
  → يُعالَج قبل توجيه الأوامر ويعود فوراً
  → يُحفظ في users database (حقل language)
  → كل الواجهات التالية بلغة جديدة
```

- **لا يُعاد تسجيل** المستخدم المسجّل عند تغيير اللغة (مغطّى باختبار).
- ثلاث طبقات: Native Flow أفقي ← `buttonsMessage` ← نص مرقّم.
- الأزرار القديمة تعمل: شبكة أمان في `src/handler.js` تعيد تحليل أي معرّف زر
  لا يُفسَّر كأمر، و`getMessageBody` يدعم **9 صيغ** مختلفة لردود واتساب.
- إرسال `terboo_language_ar` كنص عادي **لا يُنفَّذ** — يُقبل من ضغطة زر فقط.

## 7. الذكاء الاصطناعي الطبيعي

`src/lib/terboo-ai-assistant.js` + `src/lib/terboo-ai-intents.js`

### متى يعمل

| السياق | الشرط |
| --- | --- |
| الخاص | أي رسالة نصية — **بلا بادئة** |
| المجموعة | رد على رسالة البوت **أو** Mention للبوت فقط |

لا يرد على رسائل المجموعة العشوائية. لا يقاطع جلسة تسجيل أو لعبة أو مسابقة
جارية. الرابط المجرّد يُترك لنظام التحميل التلقائي. Bot Loop Guard كما هو.

### Universal Command Bridge

لا توجد قائمة أوامر ثابتة. الفهرس يُبنى **تلقائياً** من `pluginStore`:

```
رسالة المستخدم
  → فهم النية (قاموس دلالي: عربي فصيح + لهجة مصرية + English + Español)
  → بحث في سجل الأوامر الحقيقي (اسم + مرادفات + وصف + استخدام + مثال + فئة)
  → ترشيح أفضل 22 أمراً يملك المستخدم صلاحيتها
  → النموذج يختار أمراً واحداً ويستخرج الوسائط
  → إعادة كتابة m.body كأمر حقيقي
  → مسار الأوامر الطبيعي: الصلاحيات + المجموعة/الخاص + التسجيل + التبريد + الطاقة
  → تنفيذ الـhandler الأصلي نفسه
  → النتيجة بلغة المستخدم
```

**أي بلوقن جديد يصبح قابلاً للاكتشاف تلقائياً** — الفهرس يُعاد بناؤه كل دقيقة.

### أمثلة مُختبَرة

| ما يكتبه المستخدم | ما يُنفَّذ |
| --- | --- |
| «ممكن تشيل الشخص ده من الجروب؟» | `طرد` |
| «خلي أحمد مشرف» | `ترقية` |
| «اعرض البروفايل بتاعي» | `بروفايل` |
| «ابعت القائمة» | `menu` |
| «هاتلي أمر تحميل فيديو تيك توك» | `تيك_فيديو` |
| «quiero descargar un video de tiktok» | `تيك_فيديو` |
| «اعمل ملصق» | `لملصق` |

المطابقة تجمع: تطابق مباشر · تطابق جزئي · تسامح مع الأخطاء الإملائية
(Jaro-Winkler ≥ 0.82) · مرادفات النية · تجريد أداة التعريف «ال».

### الأمان

- **لا صلاحيات مستقلة للـAI** — لا يُكرَّر منطق الصلاحيات إطلاقاً، فقط
  `m.body` يُعاد كتابته ثم يمر الأمر على `checkPermission` الأصلي.
- لا يُرشَّح أمر لا يملك المستخدم صلاحيته أصلاً (owner / premium / admin / group).
- البوت ليس مشرفاً → لا يحاول تنفيذ أمر يحتاج صلاحية بوت.
- هدف غير واضح → **يسأل** ولا يخمّن عضواً. الهدف يُستخرج من الإشارة أو الرد.
- حد معدّل 4 ثوانٍ لكل مستخدم.
- **لا eval ولا تنفيذ كود عشوائي** إطلاقاً.
