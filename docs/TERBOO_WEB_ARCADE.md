# 🎮 Terboo Web Arcade + موقع البوت الديناميكي

## الفكرة
كل ألعاب الأركيد (23 لعبة) لها واجهة HTML تفاعلية حركية على موقع البوت نفسه:
XO بحبر نيون وخط فوز، أقراص تسقط، بطاقات تنقلب، 2048، السلم والثعبان ببيادق متحركة،
ثعبان/طوب حيّ، بطاقات أسئلة، وردل… مع أصوات مولّدة وقصاصات احتفال.

اللعب **من واتساب**: بطاقة اللعبة تحمل زر «🎮 العب تفاعلياً».
- في الخاص: زر رابط مباشر (رابط شخصي لمقعدك).
- في المجموعة: الزر يرسل لكل لاعب رابطه الشخصي في الخاص (لا يُنشر رابط في المجموعة).

اللعب **من الموقع**: الصفحة الرئيسية تعرض معرض الألعاب؛ بعد تسجيل الدخول بواتساب (`.ويب <الرمز>`)
تبويب «الألعاب» يبدأ لعبة ضد الكمبيوتر مباشرة.

## الأمان (Server-Authoritative)
- رابط `/play/<token>`: رمز HMAC يحمل {الغرفة، الجلسة، معرّف اللاعب، الانتهاء 6 ساعات} — لا JID خام.
- الصفحة لا تحسب أي نتيجة: ترسل `{actionId, payload, nonce, timestamp}` فقط ⇒ `engine.applyAction(source:"html")`
  يطابقها حرفياً مع الحركات القانونية، ويرفض القديم/المكرر/الموقّت والحقول المحظورة (winner/score/turn…).
- POST يقبل JSON + رأس `X-Terboo-Arcade: 1` فقط، ومنشأ نفس الموقع فقط، وحد معدّل مستقل.
- العرض المرسل للمتصفح بلا JID أو معرّف لاعب أو حالة اللعبة الخام.
- CSP صارمة (`script-src 'self'`) ولا `innerHTML` لنصوص الخادم.

> ملاحظة: عرض HTML داخل فقاعة واتساب نفسها يتطلب انتحال ردود Meta AI بتوقيعات تحقق مزيفة — غير مدعوم عمداً.
> البديل المعتمد: صفحة اللعب التفاعلية على موقعك + أزرار واتساب.

## رابط الموقع (ديناميكي)
الترتيب:
1. رابط ضبطه المالك من البوت (`.موقع رابط …`)
2. `config.website.url` / `TERBOO_SITE_URL`
3. لا شيء ⇒ تلقائياً `http(s)://<IP السيرفر العام>:<المنفذ>/` (IP من `TERBOO_PUBLIC_IP` أو واجهة الشبكة أو ipify)

بلا رابط مضبوط يستمع الخادم على `0.0.0.0` ليعمل رابط IP:المنفذ. رابط دومين بلا منفذ ⇒ يستمع على `config.website.host` (خلف reverse proxy).

## أوامر المالك
| الأمر | الوظيفة |
|---|---|
| `.موقع` | الحالة + أزرار (تشغيل/إيقاف/إعادة/رابط تلقائي/SSL تلقائي/فتح الموقع) |
| `.موقع رابط https://domain` | رابط عام (دومين أو IP) |
| `.موقع رابط تلقائي` | العودة للرابط التلقائي IP:المنفذ |
| `.موقع منفذ 8787` | منفذ الاستماع |
| `.موقع تشغيل` / `ايقاف` / `اعادة` | التحكم في الخادم وقت التشغيل (بلا إعادة تشغيل البوت) |
| `.موقع ssl <cert.pem> <key.pem>` | HTTPS من ملفات (تُفحص الصلاحية والتطابق) |
| `.موقع ssl تلقائي [بريد]` | شهادة Let's Encrypt عبر certbot (يحتاج دوميناً يشير للسيرفر والمنفذ 80 متاحاً) |
| `.موقع ssl ايقاف` | العودة لـ HTTP |

الإعدادات تُحفظ في قاعدة البيانات (`website:runtime`) ولا تُكتب في `config.js`.

## متغيرات بيئة اختيارية
`TERBOO_PUBLIC_IP` · `TERBOO_WEB_PORT` · `TERBOO_WEB_HOST` · `TERBOO_WEB_SSL_CERT` · `TERBOO_WEB_SSL_KEY`
