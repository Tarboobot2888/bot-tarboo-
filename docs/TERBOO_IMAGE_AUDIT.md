# فحص صور Bot Terboo + حزمة «Neon Shinobi» بدقة 1080

> فحص شامل لكل صورة في `assets/` ولكل نظام يرسم صوراً وقت التشغيل، ثم حزمة صور جديدة بالكامل بشخصية
> واحدة ثابتة («Neon Shinobi / Cyber Sentinel»): نينجا سايبر أصلي، واسم **TERBOO** كبير **خلفه**، وكل النصوص بالإنجليزية فقط.
> المولّد: `tools/terboo-brand-assets.mjs` (التخطيطات والطبقات) + `tools/terboo-brand-art.mjs` (الشعار والطباعة). البيان: `docs/terboo-asset-manifest.json`.

## 2. الهوية «Neon Shinobi»

- **الشخصية:** نينجا سايبر أصلي واحد في كل الصور: شعر أسود مدبّب · قناع أسود · عينان بنفسجيتان متوهّجتان · درع تكتيكي أسود بياقة عالية · كاتانتان متقاطعتان خلفه. أوبسيديان `#050508` + بنفسجي `#a855f7` + سماوي `#22d3ee` + لمسات ماجنتا، ولون القسم لمسة خفيفة فقط (توهّج الحافة والشعار الهولوغرامي).
- **الاسم خلف الشخصية:** «TERBOO» بخط **Anton** (عريض مكثّف، OFL) بتدرّج أبيض ← بنفسجي، وضربة كاتانا تقطع الحروف بلمعة، وظل حدّي سماوي مُزاح وتوهّج خلفي. الطبقات: المشهد ← الاسم ← الشخصية مقصوصة بقناعها ← النصوص. موضع الاسم وحجمه يُحسبان لكل صورة من قناع الشخصية: لا يختفي حرف كاملاً، والرأس يغطي أسفل الحروف الوسطى فقط (كغلاف مجلة)، وإن لزم يُنزَل المشهد قليلاً بتلاشٍ علوي ناعم.
- **الشعار:** T زاوي مندمج بفقاعة محادثة + قطع كاتانا (قلب أوبسيديان · حافة بنفسجية · لمعة سماوية) و«BOT TERBOO» بأحرف كبيرة.
- **الفن:** مشاهد Canva AI مولّدة بالشخصية الرئيسية مرجعاً (تصميم «Bot Terboo — Neon Shinobi Art» في حساب Canva)، ثم:
  1. **تكبير ×4 بـ Real-ESRGAN (anime 6B)** إلى 4320 ثم تصغير ناعم إلى **2160×2160** — تفاصيل وخطوط حادة لا مجرد تمطيط (Canva يصدّر 1080 فقط في هذا الحساب).
  2. **قناع الشخصية بـ BiRefNet** (`<المشهد>-mask.png`) — يشمل الكاتانتين.
  المشاهد الجاهزة في `tools/brand-art/shinobi/`. رصيد Canva AI محدود (يتجدد ببطء)، فالقسم الذي لم يُولَّد مشهده بعد يأخذ أقرب مشهد للونه مع قلب/تقريب مختلف وشعار هولوغرامي خاص به؛ وكل مشهد جديد يُولَّد يحل محله تلقائياً عند إعادة التوليد.
- **الخطوط:** عناوين Plus Jakarta Sans ExtraBold · نص Inter · الاسم الكبير Anton.
- لا شعارات أو شخصيات أو علامات لأي جهة أخرى (لا Meta AI ولا ChatGPT ولا غيرهما).

## 3. الحزمة (71 صورة) ودقتها

- **1080 (تُرسل صورةً كاملة):** صور الأقسام الـ42 ولافتة القائمة ومواقيت الصلاة (1920×1080) · القوانين والتسجيل (1080×1080) · الترقية (1442×1080) · التنزيل (1080×1595). كل صورة تُرسم بضعف مقاسها (والفن 2160 مكبّر بالذكاء الاصطناعي) ثم تُصغَّر بـ lanczos مع توضيح خفيف ⇒ نصوص وحواف واضحة بحجم ~300 KB للصورة.
- **مصغّرات داخل الرسائل (تبقى صغيرة عمداً):** `terboo.png` · `terboo2.jpg` · الألعاب · الفائز · RPG · المستوى · ماينكرافت · الصيد · صور الردود العشوائية… هذه يضعها البوت في `jpegThumbnail`/`thumbnail` داخل الرسالة نفسها، وواتساب يعرضها بحجم طابع صغير؛ صورة كبيرة هناك تضخّم كل رسالة وقد تُرفض. لذلك تبقى بمقاسها.
- **وظيفية:** ورق `.كتابة_يدوية` 1024×784 (الأمر يكتب على هذه الإحداثيات) · الصورة الشخصية الفارغة 1200×1200.
- **الأقسام (42):** «SECTION NN» · عنوان إنجليزي · سطر وصف · شعار هولوغرامي برمز القسم في أفرغ موضع حول الشخصية.
- **الردود العشوائية (8):** `assets/image/shuffle/`.

## 6. إعادة التوليد

```bash
node tools/terboo-brand-assets.mjs              # يكتب الصور + البيان (3 صور معاً؛ TERBOO_RENDER_JOBS لتغييرها)
node tools/terboo-brand-assets.mjs --out /tmp/x # معاينة دون لمس assets
node tools/terboo-brand-assets.mjs --only=sections/ai.jpg --out /tmp/x
```
مشهد جديد: ضع `tools/brand-art/shinobi/<المفتاح>.jpg` (2160×2160) و`<المفتاح>-mask.png` بنفس الاسم الذي في `SECTION_DATA`/`SPEC`، ثم أعد التوليد.

الاختبار: `tests/terboo-brand-assets.test.mjs` (كل قسم له صورة 1920×1080 · المصغّرات صغيرة · المشاهد 2160 ولها أقنعة · خط Anton وترخيصه · shuffle من الهوية · الورق بمقاس الأمر · البصمات تطابق البيان · لا نص عربي مرسوم).
